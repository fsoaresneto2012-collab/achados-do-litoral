# Achados do Litoral

Vitrine de achados do Mercado Livre (achadosdolitoral.com.br).

- `index.html`: layout da página
- `produtos.json`: lista de produtos (nome, categoria, preço, preço anterior, nota, vendidos, foto, link de afiliado meli.la)
- `img/`: fotos guardadas no próprio site

Para adicionar um produto, inclua um item em `produtos.json`.
